# 人工知能演習の自由課題: 学習環境と機械側のPPO（11/12〜11/25）

2026-11-12 / 対象: 人工知能演習（2人チーム、成果発表 11/25）の自由課題として、`plans/2026-11-06_ai-selfplay-league.md`（以下、11/06計画）の Step 1 と、Step 4 を縮めたものを行う。学習には自動盤と同じ C++ コアを使い、ルールの実装を一本に保つ。11/06計画のほかの部分はこの期間には手を付けず、12月以降に元の計画どおり進める。

## 1. 決めたこと

- ルール: RE＋RW＋RU40（`edgeCapture = true`、`wallLimit = true`、`untouchedMs = 40000`）。4枚先取、時間切れ10分（`timeLimitMs = 600000`）。学習中は固定する。RU の時間は 11/06計画の所見（RU40 は RU20 より B1 との局が長く、勝率の落ち方も小さい）から 40 秒にした。20 秒と比べるのはこの期間ではやらない。
- 学習するのは機械側だけ。人間側は環境の中の固定のボット（B1 と Race）が指す。
- 学習は Azure の VM（T4）で回す。予算は1人約1,335ドル。使わないときは VM を止める。

## 2. この期間にやらないこと

人間の主役と攻略役（リーグ、PFSP）、参照方策への KL 正則化、制約つき PPO（活動は記録だけする）、整数の推論と ESP32・WASM への書き出し、RaceTime の入力、模倣学習からの出発、対局の記録の保存。

## 4. 環境の約束（Python から見た形）

```python
env = hasami_env.BatchEnv(n_envs=256, seed=1, opponent="b1",   # "b1" | "race" | "random"
                          speed_scale=1.0)                       # 機械の freeSpeed・dragSpeed・engageMs への倍率
obs, scal, mask = env.reset()
obs, scal, mask, reward, dt_ms, done, info = env.step(actions)
```

| 名前 | 型と形 | 中身 |
|---|---|---|
| `obs` | int16 [N, 12, 7, 7] | 下の12チャンネル |
| `scal` | int16 [N, 6] | 機械の取った枚数、人間の取った枚数、残り時間（100ms単位）、Opening中か、機械が開始の一手を指し終えたか、speed_scale×100 |
| `mask` | bool [N, 1177] | 合法な行動。1176番の「動かない」は常に真 |
| `actions` | int32 [N] | 行動の番号 |
| `reward` | float32 [N] | 前の決定点からこの決定点までの報酬の合計（11/06計画 3.3 の機械の報酬。引き分けの毎秒の罰を含む） |
| `dt_ms` | int32 [N] | 前の決定点からの経過時間。割引は γ^(dt/τ)、半減期120秒 |
| `done` | bool [N] | 局の終わり。終わった局はその場で自動で reset し、`obs` は新しい局の最初の決定点を返す |
| `info` | dict of arrays | `winner`（0なし・1人間・2機械）、`captures`、`activity`（外にいた割合など、記録用） |

- `step` は、機械に合法な行動が2つ以上ある次の決定点まで時間を100ms刻みで進めて返す（11/06計画 3.4）。決定は読みの間隔 `max(150, reactMs)` ごと。Removing と Countdown のあいだは決定点にしない。
- 座標は盤の向きのまま（r=0 が機械の一段目、c=0 が左端）。鏡像は使わない。
- 行動の番号: `((r*7 + c)*4 + d)*6 + (dist-1)`。方向 d は `Board.h` の DIR の順（0 下、1 上、2 右、3 左）。1176 が「動かない」。動かす駒の元のマスで指定し、機械は行く手が埋まれば手前で止まる（Game のルールどおり）。
- チャンネル（値は整数）: 0 機械の駒、1 人間の駒、2 人間が持ち上げ中の駒の元のマス、3 人間の保留先、4 機械が確保中のマス、5 機械の駒のクールダウン残り（100ms単位）、6 人間の駒のクールダウン残り、7 機械の駒の RU の残り（100ms単位、RU で取られうるようになるまで）、8 人間の駒の RU の残り、9 ヘッドの位置、10 機械が動かしている駒の行き先、11 RE で取られうる（空きがあと1つの）端のまとまりの駒。

## 5. 評価と実験

- 比べるもの: 学習した方策と、今の手書きの読み（つよい）。相手は B1 と Race、各200局、種を固定する。数字は勝率、1局あたり取った枚数と失った枚数、引き分けの割合、機械の駒が一段目の外にいた割合。
- 実験: 機械の速さの倍率 speed_scale を 0.7、1.0、1.3 にして学習し、同じ相手への勝率がどう変わるか（遅い機械でも読みで補えるか）。
