### センサの品番と磁石の枚数（OA と PA、`cal` → `hall`）

磁石を近づけない状態で `cal` を打ち、センサの中心値と磁場ゼロの mV を測ってから `hall` で読む。`hall` は生の値、中心からの差、mV（`analogReadMilliVolts`）、OA と PA それぞれの感度で見積もった mT（＋がS極、−がN極）を出す。各欄に「生の値 / mV / その品番の mT」を書く。DRV5053 は磁場0で約1.02V（0.9〜1.15V）、S極で下がりN極で上がる。OA は −11mV/mT で 73mT、PA は −23mV/mT で 35mT で飽和する（出力 0.2V〜約1.8V）。仮のしきい値は enter 6mT、exit 3mT（OA で 82・41カウント、PA で 171・86カウント）。`hall` の判定（class の列）は `lib/hw/Pins.h` の `HALL_SENSOR` の品番のしきい値を使うので、PA のセンサで判定まで見るときは `HALL_SENSOR` を `Drv5053::PA` にして書き込み直す（mV と mT の列は品番によらない）。

### 電磁石の発熱（`heat s d`）

`heat s d` は電磁石を PullMachine でデューティ d のまま s 秒通電し（吸着後の保持デューティへの切り替えはしない）、通電した時間を出す。止まったらすぐにコイルの温度を測る（温度計、熱電対、放射温度計など）。測るごとに室温まで冷ます。電磁石は 12V 0.33A（約4W、販売元の値）で、通電を続けると熱くなると説明されている。

### 保持デューティ（`hold d` → `pull v a`）

Pull に切り替えた直後は `Magnet::PULL_DUTY`（255）で `Magnet::BOOST_MS`（300ms、仮）、そのあと保持デューティに下げる。既定の `HOLD_DUTY` は 255（下げない）。`hold d` で保持デューティを変えて `pull v a` を試し、駒が取り残されない最も低い d を探す。`pull` は終わりに通電した時間も出す。

## 盤の食い違いによる一時停止（本番ファーム、後日）

計画 `plans/2026-10-31_ai-time-race.md` の 3.2。本番ファーム（`pio run -e esp32dev -t upload`）で、ゲーム中に次を試す。食い違いが 300ms（`src/main.cpp` の `MISMATCH_MS`）続くと一時停止し、シリアルに `mismatch: paused` が出る。

| 確かめること | 手順 | 合格の目安 | 結果 | 日付 |
|---|---|---|---|---|
| 駒を滑らせても止まらない | 持ち上げずに人間の駒を盤面に沿って1〜3マス滑らせて置く（速め・ゆっくりの両方） | 通り道のマスで一瞬検出された分では一時停止しない（`mismatch: paused` が出ない） | | |
| 滑らせる速さの下限 | ゆっくり滑らせ、1マスに 300ms 以上とどまる速さを探す | 一時停止する速さを書く（300ms の待ちを変えるかの判断に使う） | | |
| 反則の置きで止まる | 置けないマス（斜めなど）に置く | 約 300ms で一時停止し、置いたマスが赤で点滅、元のマスは行き先の青のまま | | |
| 持ち上げ上限の時間切れで止まる | 持ち上げて 1 秒以上持ったままにして別のマスに置く | 元のマスが白、置いたマスが赤で点滅 | | |
| 元に戻すと再開する | 上の2つのあと、駒を正しいマスへ戻す | 一致が 300ms 続いたら `mismatch: resumed`、1 秒のカウントダウンのあと Play に戻る | | |
| 運び出し中に止まる | 運び出しの最中に別の駒を動かす | 引いている途中の1マスを引き終えて止まり、運んでいる駒を離さない。戻すと続きを運ぶ | | |
| 再開後の持ち上げ・置き | 再開のあと、ふつうに持ち上げて置く | Lift・Place がふだんどおり受け付けられる | | |
