# 1マス試作の印刷部品（段階1: 手で動かす台車）

制作計画（`plans/2026-10-30_realtime-hasami-board.md`）の1マス試作のうち、モーターなしで測る段階1の部品。組み立てと測定の手順は Claude Docs の「1マス試作 完全ガイド」にある。

| ファイル | 部品 | 数 | 材料（プリンター） | 大きさ（mm） |
|---|---|---|---|---|
| `stl/frame.stl` | 台。台車が走る溝と、格子板を載せる壁 | 1 | PLA（AFINIA H800） | 150×70×34 |
| `stl/sled.stl` | 台車。電磁石を載せる受け皿と取っ手 | 1 | ABS（AFINIA H+1）。電磁石の熱で PLA は柔らかくなるため | 156×31×13 |
| `stl/grid.stl` | 格子板。3マス分、中央がセンサーと LED の窓 | 1 | PLA（白が望ましい） | 120×45×3 |
| `stl/jig.stl` | 位置決めの型。駒を中心と 3.6mm ずらした位置に置く | 1 | PLA | 123×48×7 |
| `stl/piece_base.stl` | 駒の台座。底から磁石を入れる | 2 | PLA（半透明） | φ28×8 |
| `stl/piece_body.stl` | 駒の本体 | 2 | PLA（人間は白か生成り、機械は黒） | φ22×14 |
| `stl/spacer.stl` | 磁石が 3 枚未満のとき、台座の穴の奥に入れる | 4 | PLA | φ9.8×2 |

- STL は、そのまま印刷する向きで出してある（位置決めの型は裏返し）。どれもサポートなしで印刷できる。
- 積層は 0.3mm（実験室の wiki の注意どおり）。
- 寸法はデータシートの値に 0.3〜1.0mm の余裕を持たせてある。測る道具がなくても、部品を組めば高さが決まる（駒の磁石から電磁石まで 7mm）。
- 電磁石は、台車の底から M4 のねじ（なべ形の頭、長さ 8mm 前後）で背面のねじ穴に留める。ねじの頭は深さ 3.4mm のくぼみに沈み、頭の下の板は厚さ 1.0mm、頭の座面から電磁石の背面までは 3.6mm。台は 4 つの穴（φ4.5）で、M4 のねじ（長さ 10〜12mm）を合板の下穴（φ3）にねじ込んで留められる。M3 の部品は使わない。
- 位置決めの型の縁には、格子板の辺から出るセンサー（幅 8mm）と LED（幅 11mm）の線を通す切り欠きがある。

寸法を変えるときは `make_parts.py` の最初の数字を直し、次で STL を作り直す。

```bash
pip install manifold3d trimesh numpy && python hardware/rig/make_parts.py
```
