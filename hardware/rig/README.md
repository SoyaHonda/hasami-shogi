# 1マス試作の印刷部品（段階1: 手で動かす台車）

制作計画（`plans/2026-10-30_realtime-hasami-board.md`）の1マス試作のうち、モーターなしで測る段階1の部品。組み立てと測定の手順は [1マス試作ガイド](../../docs/rig-guide.md)（`docs/rig-guide.md`）にある。

| ファイル | 部品 | 数 | 材料（プリンター） | 大きさ（mm） |
|---|---|---|---|---|
| `stl/frame.stl` | 台。台車が走る溝と、格子板を載せる壁 | 1 | PLA（AFINIA H800） | 150×70×34 |
| `stl/sled.stl` | 台車。電磁石を載せる受け皿と取っ手 | 1 | ABS（AFINIA H+1）。電磁石の熱で PLA は柔らかくなるため | 156×31×13 |
| `stl/grid.stl` | 格子板。3マス分、中央がセンサーと LED の窓 | 1 | PLA（白が望ましい） | 120×45×3 |
| `stl/jig.stl` | 位置決めの型。駒を中心と 3.6mm ずらした位置に置く | 1 | PLA | 123×48×7 |
| `stl/piece_base.stl` | 駒の台座（下半分）。将棋の駒（歩兵）の形で、真ん中に磁石の部屋がある | 2 | PLA（半透明） | 22.5×27×4 |
| `stl/piece_body_fu.stl` | 人間の駒の本体（上半分）。台座と同じ外形で、上面に「歩」を彫ってある | 1 | PLA（白か生成り） | 22.5×27×5.55 |
| `stl/piece_body_to.stl` | 機械の駒の本体（上半分）。同じ外形で、上面に「と」を彫ってある | 1 | PLA（黒） | 22.5×27×5.55 |
| `stl/spacer.stl` | 磁石が 1 枚のとき、磁石の上に載せる | 2 | PLA | φ9.8×2 |

- `laser/acrylic.svg`、`laser/acrylic.dxf`: 乳白アクリル（2mm）の外形 118×43mm。CO2 レーザーカッターで切るときに読み込む（単位は mm、切る線は赤）。店でカットしてもらうか P カッターで切るなら要らない。
- STL は、そのまま印刷する向きで出してある（位置決めの型と駒の本体は裏返し。本体は文字の面が下になる）。どれもサポートなしで印刷できる。
- 積層は 0.3mm（実験室の wiki の注意どおり）。
- 駒は実物の歩兵の大きさ（縦 27mm、幅 22.5mm、厚さ 7.75mm）の五角形で、同じ外形の台座（下 4mm、半透明）と本体（上 3.75mm）を重ねる。本体の下の出っ張り（高さ 1.8mm）を台座のくぼみに押し込むと、向きがそろってはまる。出っ張りの側面は壁から片側 0.2mm 離してあり、そこに付けた 8 本の三角の突起（つぶれリブ）だけが壁に 0.25mm 食い込む。押し込むと突起の先がつぶれて止まるので、プリンターが少し太めや細めに刷っても、がたつかずにきつくはまる。食い込みは `RIB_BITE`、すき間は `PIECE_FIT` で変えられる。継ぎ目の V 溝（0.4mm）は、こじ開けるためのもの。
- 磁石（φ10×2mm）は、外形の縦横の真ん中にある部屋（φ10.3、高さ 4.2mm、2 枚分）に閉じ込める。部屋の床は厚さ 0.6mm なので、磁石から電磁石までは 7.6mm になる。
- 本体の文字は深さ 0.9mm（0.3mm の層 3 枚分）の彫り込みで、塗料やペンで色を入れる。字体は Noto Sans JP の太字（SIL Open Font License）で、線の太さは 1mm 前後ある。フォントは `C:/Windows/Fonts/NotoSansJP-VF.ttf` を読む。ほかの場所にあるときは、環境変数 `LABEL_FONT` でそのファイルを指定する。文字や大きさは `make_parts.py` の `PIECE_LABELS`、`LABEL_H` で変えられる。
- 寸法はデータシートの値に 0.3〜1.0mm の余裕を持たせてある。測る道具がなくても、部品を組めば高さが決まる（駒の磁石から電磁石まで 7.6mm）。
- 電磁石は、台車の底から M4 のねじ（なべ形の頭、長さ 8mm 前後）で背面のねじ穴に留める。ねじの頭は深さ 3.4mm のくぼみに沈み、頭の下の板は厚さ 1.0mm、頭の座面から電磁石の背面までは 3.6mm。台は 4 つの穴（φ4.5）で、M4 のねじ（長さ 10〜12mm）を合板の下穴（φ3）にねじ込んで留められる。M3 の部品は使わない。
- センサーと LED の線は、どちらも格子板の奥（+y）の辺から出る（LED の溝は窓の右からセンサーの窓の先で合流する）。位置決めの型の縁には、その線をまとめて通す切り欠きがある。曲がるジャンパーが 20cm でも、ブレッドボードを台の奥の左寄りに置けば届く。

寸法を変えるときは `make_parts.py` の最初の数字を直し、次で STL を作り直す。

```bash
pip install manifold3d trimesh numpy fonttools && python hardware/rig/make_parts.py
```
